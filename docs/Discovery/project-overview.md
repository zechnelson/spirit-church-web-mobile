# Project Overview

> Last Updated: 2026-05-14

## Description

A mobile-first website that allows users to see upcoming events, links to pages on the church website, and the ability to take sermon notes while listening to the sermon live in-person.

## Goals

1. Surface upcoming church events in a clean, mobile-optimized view
2. Provide quick-access links to key pages on the main church website
3. Enable live sermon note-taking during in-person services
4. Keep the experience fast, simple, and accessible on any phone
